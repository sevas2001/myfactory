# myfactory

Repositorio central para skills, agentes y configuraciones de desarrollo en Antigravity.

---

## Estructura del Repositorio

- **`scenario-skills/`**: Colección de skills y agentes para workflows creativos y generación de contenido (imágenes, video, audio, modelos 3D y flujos de Scenario).  
  *Origen:* [scenario-labs/skills](https://github.com/scenario-labs/skills)

- **`blender-game-skills/`**: Skills especializadas para modelado, conversión de imágenes a 3D, texturizado y validación para motores de videojuegos con Blender.  
  *Origen:* [majidmanzarpour/blender-game-skills](https://github.com/majidmanzarpour/blender-game-skills)

---

## Uso

Cada subcarpeta contiene sus respectivos manuales y definiciones de skills (`SKILL.md`), scripts de utilidad y documentación. Puedes modificar o añadir nuevas skills y agentes según las necesidades de tus proyectos.
